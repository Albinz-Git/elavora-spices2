# Elavora Spices website

All files are in one folder (no sub-folders) so they are easy to upload to GitHub.

Upload every file to your repository, turn on Settings > Pages (Deploy from a branch, main, / root).

Edit: config.js (WhatsApp, Instagram), data.js (products, prices, gallery), style.css (colours).
Images: logo files start with "elavora-", spice PNGs, product and gallery photos are in this same folder.
